Shadow Lipibangla - PROTECTED FONT

ShadowLipibangla.ttf is a permanent part of the Shadow GNU/Linux identity.

This font is installed system-wide in /usr/share/fonts/truetype/custom/ and
must never be removed, purged, pruned, optimized away, or replaced by the
build system, cleanup hooks, or font-cache tooling.

It is intentionally NOT set as a system-wide default font; systems should
keep their normal lightweight GUI fonts and Unicode fallback (e.g. DejaVu,
Noto Core subsections). This font is reserved for terminal/monospace and
specific Shadow usage.

- Checked by variants' cleanup hooks at build time.
- Permissions are kept at 0644.
